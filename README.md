# Fortinet Docs Downloader

Portable Windows-native CLI for discovering and downloading PDF documentation from the Fortinet Document Library.

This project targets restricted Windows workstations. The supported runtime path uses only Windows inbox tooling, specifically `cmd.exe` and `curl.exe`, with no PowerShell, Git, Python, Node.js, package manager, unsigned custom executable, or administrative installation requirement.

Current development target: **v0.0.1**.
