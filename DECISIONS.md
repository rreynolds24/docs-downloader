# Decisions

## 2026-10-07

- Build v0.0.1 as a native Windows batch utility.
- No PowerShell anywhere in the supported path.
- Do not ship an unsigned custom executable.
- Use Windows inbox `curl.exe` for HTTP/PDF retrieval.
- Use a Fortinet-branded interactive terminal banner based on the fortinet-branding 2.3.0 convention.
- Scope v0.0.1 to a single Fortinet product/version URL.
- Treat network access as application functionality, not an installation dependency.
